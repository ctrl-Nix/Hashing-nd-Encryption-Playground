WHY MD5 IS BROKEN FOR PASSWORDS
1. Speed is the enemy. MD5 was designed to be fast — a modern GPU can compute billions of MD5 hashes per second.
2. No salt by default. The same password always produces the same hash, enabling pre-computed rainbow table attacks.
3. Collision vulnerability. Two different inputs can produce the same MD5 hash, undermining integrity guarantees.
// FIX: Use purpose-built password hashing like bcrypt, scrypt, or Argon2 — they are intentionally slow and include built-in salting.
