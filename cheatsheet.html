Quick Reference Guide for Applied Cryptography

AES-GCM SYMMETRIC

TYPE
Authenticated Symmetric Encryption
KEY SIZE
128, 192, 256 bits
USE CASES
Bulk data encryption, secure file storage, TLS/HTTPS payloads, databases.
NOTES
Provides both confidentiality AND integrity. Requires a strictly unique Initialization Vector (IV) / Nonce for every encryption.

SHA-256 HASHING

TYPE
Cryptographic Hash Function
OUTPUT
256 bits (32 bytes)
USE CASES
File integrity verification, blockchain proofs, generating message digests for digital signatures.
NOTES
One-way deterministic function. For password storage, it MUST be wrapped in a key derivation function (like PBKDF2, Argon2) with a unique salt.

ECDSA ASYMMETRIC

TYPE
Digital Signatures
KEY SIZE
256, 384, 521 bits (P-256 is common)
USE CASES
Authenticating software updates, JSON Web Tokens (JWTs), cryptocurrency transactions, proving identity.
NOTES
You Sign with your Private Key (proving you sent it). Anyone can Verify with your Public Key.

ECDH ASYMMETRIC

TYPE
Key Exchange Agreement
KEY SIZE
256, 384, 521 bits
USE CASES
Establishing a shared secret over a public/insecure channel, TLS handshakes, End-to-End encrypted messaging (Signal).
NOTES
Mix your Private Key with their Public Key to derive the exact same symmetric key without ever transmitting secrets.

HMAC AUTH CODE

TYPE
Message Authentication Code
KEY SIZE
Variable (depends on underlying hash)
USE CASES
Validating API webhooks, generating stateless session tokens, preventing parameter tampering.
NOTES
Proves both data integrity AND authenticity, because computing the matching hash requires knowing the shared secret password.

DO NOT USE DEPRECATED

MD5 (128-bit)
Severely compromised by fast collision attacks. A modern GPU can brute-force billions of MD5 hashes per second. Safe only for non-cryptographic file checksums to detect accidental corruption.
SHA-1 (160-bit)
Mathematically broken (SHAttered attack). Capable of generating collisions where two different files produce the same hash. Completely deprecated for digital signatures and certificates.
